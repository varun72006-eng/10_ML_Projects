## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/varun72006-eng
```

Go to the project directory:

```bash
cd 10_ML_Projects
```

Create a virtual environment:

```bash
python -m venv venv
```

Activate it on Windows:

```bash
venv\Scripts\activate
```

Install the required dependencies for the particular project:

```bash
pip install -r requirements.txt
```

> Some projects may have their own `requirements.txt` and setup instructions. Check the individual project folder before running it.
